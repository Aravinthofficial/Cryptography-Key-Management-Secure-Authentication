# Cryptography-Key-Management-Secure-Authentication
## Project Status

✅ Completed

## Objective

Implement secure cryptographic protocols and authentication techniques using Python.

## Technologies Used

- Python 3
- AES-256-GCM
- RSA-2048
- HMAC-SHA256
- bcrypt
- cryptography library

## Features

This project demonstrates:

1. AES-256-GCM symmetric encryption and decryption
2. Random IV generation
3. RSA-2048 public/private key generation
4. RSA digital signature creation and verification
5. HMAC-SHA256 generation and verification
6. Secure password hashing using bcrypt
7. Secure secret and key management practices
8. Cryptographic key rotation practices
